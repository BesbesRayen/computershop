## 🚀 HOW TO GET STARTED

### 🔴 CRITICAL: Firebase Setup (5 min)
```bash
1. Go to console.firebase.google.com
2. Create project "TIJARA"
3. Register Android app (package: com.example.computershop)
4. Download google-services.json
5. Place in: app/google-services.json
6. Enable Email/Password authentication
7. Create Firestore database
8. Create collections: Internaute, Article, Panier
```
